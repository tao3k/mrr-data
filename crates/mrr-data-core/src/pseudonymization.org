#+TITLE: Pseudonymization Input Binding
#+OPTIONS: toc:nil

The =pseudonymization= feature exports
[[file:pseudonymization.rs][PseudonymizationInputBinding]]. It relates one selected value digest,
field, per-record context, and consumer-owned profile to an immutable
snapshot root and semantic generation. The type is generic in the profile:
downstream code can use the public =cedar-poo-bridge/pseudonymization= token
profile, another declared recipe, or an application profile without adding
Cedar to =mrr-data-core=.

This binding does not select a table cell, authenticate the declared profile
or key, perform AES-SIV/HMAC, call Google Sensitive Data Protection, or
authorize token release. The Host authenticates the selected input and
context, executes the chosen provider, and binds its response and output
bytes to the admitted operation. The generic Lean pseudonymization capability
owns recipe and join semantics; Google SDP is one optional provider.
