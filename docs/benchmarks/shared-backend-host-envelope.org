#+LANGUAGE: en

* Reviewed scope and evidence grade

Weaver SysML GovernancePolicyProjection owns runtime responsibility and this
predeclared measurement contract. MRR Data owns the existing standard Cargo
tests and benchmark targets. No new qualification package, dependency pin,
production runtime path or authorization model is added.

The task explicitly requests direct retesting on the shared Host without waiting
for an exclusive runner, quiet load or battery/power prerequisite. Therefore
Host quality is reported rather than used to block this diagnostic run. Safety,
source identity, resource bounds and exact recovery remain hard requirements.
A favorable diagnostic number does not become controlled acceptance.

* Controlled profile and fixed acceptance

| Obligation | Controlled acceptance criterion | Diagnostic treatment |
|------------+---------------------------------+----------------------|
| Ownership | Attested exclusive measurement window; reference and owner recorded | Missing attestation disclosed; no blocking |
| CPUs | Physical/logical/available counts recorded and stable; runtime/write/shared workers and reuse capacity = max(4, available CPUs) | Same allocation; no shrink-to-pass |
| Power/thermal | AC, low-power mode off, stable disclosed profile and no thermal throttling; missing observations are not green | Record available state and missing fields |
| Quiet prefix | 30-second preflight, idle >=90%, load1 <=0.5 times logical CPUs; repeat envelope checks before/after each leg | No quiet-prefix requirement for execution |
| Memory/I/O context | Normal pressure, no cumulative swap-out growth; record device/filesystem and native sentinels | Used swap size is not cumulative swap-out evidence |
| Build identity | Same compiler/SDK/profile, immutable base+candidate source and lockfile; actual compile witness and frozen executable hashes | Mandatory in both grades |
| Safety | No unexpected refusal/failure/Unknown, exact original recovery, once-only validation and original borrowed/cancel/restart/exposure constraints | Mandatory in both grades |
| Replication | Three fixed ABBA blocks per declared contrast, with all samples | One fixed block per contrast in this retest |
| Primary benefit | Hot/reuse and independent/reuse median paired TPS >=1.10 overall and >=1.05 per block | Descriptive ratios only |
| Nonregression | Every paired TPS >=0.95 and paired P95/P99 <=1.05 in all six mode/domain strata | Report every violation; do not suppress poor samples |
| Native sentinel stability | Within variant/mode, max/min of per-round mean gets and FULL post-body <=1.10 | Report drift; no causal quality upgrade |

These are fixed engineering gates chosen before this retest, not a statistical
confidence theorem. Requests within one timed leg are not independent experimental
replications. Power/load measurements and lower-layer controls do not prove pure
native CPU or device/fsync cost; that additionally requires scheduler/thread-CPU
and process-scoped kernel I/O evidence. A Linux result is a separate profile and
cannot qualify a Darwin-specific claim.

* Experimental contrasts and unchanged workload

Use O = original, A = ready-permit admission only, AV = Condvar rendezvous plus
ready permits. Admission is O/A/A/O. Validator replacement is A/AV/AV/A: its
effect is conditional on ready admission. AV/O alone would confound two changes.
Match treatment leg 2 against reference leg 1, and treatment leg 3 against
reference leg 4, for the same mode/domain/round. A future combined promotion
needs direct AV/O confirmation; medians from separate contrasts cannot be multiplied.

All legs use the existing backend_concurrency_paired target and real bounded
filesystem reads, CID checks, strict typed-body decoding/equality and enrolled
authority checks. This is not Cedar evaluation, an LLM request or a final external
send. Each full-path leg retains all three rotated WAL/fresh/reuse rounds for
independent original homes and one original hot home. There are 64 operations
per lane, FULL, zero retries and the unchanged 30-second per-case collection
bound. Preparation and compilation finish before measurement. Accepted workers
drain and fresh owners recover every original operation/authority vector.

The 2026-10-31 retest uses 12 physical/logical/available CPUs, 12 runtime/write/
shared workers and reusable capacity, and 16 blocking threads. No task-owned
compilation/test overlaps a timed leg. Reporting and before/after Host observations
are outside timing but can affect subsequent cache/I/O state; observer effects
remain disclosed. Each binary is hashed before and after every leg.

conditional on A has hot/reuse median 2.033 and independent/reuse 1.283, but the
independent stratum includes a 0.475 TPS pair, worst P95 3.371 and P99 3.027.
The primary hot number therefore cannot establish general nonregression.

The validator contrast's first three hot/reuse ratios are 0.980, 1.184, 1.052;
the later three are 3.900, 2.881, 3.854. The large pooled median is strongly
influenced by the late reference leg. The same A executable has hot get means
136.55--149.04 microseconds and bridge residual 10.18--12.46 in reference leg 1,
but 309.86--419.88 and 131.43--311.90 respectively in reference leg 4. No source
change occurred between those reference legs. Host/runtime/cache context can
thus produce much of the apparent contrast; no exact attribution to CPU contention
alone, native MVCC code, or Condvar is justified.

In the earlier lower-latency reference/treatment pair, median bridge residual
changes from 10.66 to 8.50 microseconds, a descriptive saving of about 2.16.
Native read/post-body costs also change, so even that observation is not isolated
proof of a protocol optimization. Under that envelope, the bridge is a small
part of the roughly hundreds-of-microseconds API path. Removing a source-level
task or allocation cannot explain all the millisecond-scale regressions.

* Host observations and conclusion

All 22 leg-boundary snapshots report AC power, 12 physical/logical CPUs and normal
memory pressure. Load1 ranges 16.60--45.68, above the controlled bound of 6.
The earlier discovery sample was battery-powered; it is not the power state of
these timed legs. Per-leg idle/thermal trajectories, exclusive ownership and
cumulative swap-out are not established. Swap-used size cannot substitute for
a cumulative swap-out counter. This remains the explicitly requested shared-Host
diagnostic grade, not controlled acceptance.

No candidate is promoted: Host grade, replication, sentinel stability and several
nonregression requirements fail or remain unestablished. Safety passed in this
run; it does not waive borrowed-guard lifetime, cancellation semantics, original
unknown exposure or independent Host/SPEC premises. Existing typed held=4,
claim/reservation/history, exact nonce/operation and authority-vector recovery
remain required. Same-process reconstruction, process death and whole-machine
rollback are distinct evidence classes. No actual provider send or refund
arithmetic is exercised here.

Both source candidates remain temporary research worktrees; production runtime,
manifests and pins are unchanged. SPEC owns semantics, existing Lean/Quint owners
are reused, and benchmark quality never becomes a live permission.
