* Questions and source-level boundaries

The previous 0.475 TPS and 3.37 P95 observations are retained in
[[file:shared-backend-host-envelope.org][the previous full diagnostic record]]. This experiment separates:

1. Fresh uninstrumented A/AV/AV/A evidence, where A is ready admission and AV
   adds Condvar. This is a conditional validator comparison, never AV/O.
2. Test-only direct Connection.query versus split prepare/Statement.query
   clocks within the same provider transaction, real verified content validator,
   original authority checks, durable commit and exact recovery.
3. Public driver stage evidence versus missing thread-CPU/kernel I/O evidence.

Pinned Turso source: connection.rs query calls dangling-transaction handling,
prepare and Statement.query. prepare calls prepare_single and builds a Statement.
Statement.query acquires a shared-operation guard, resets, binds and returns Rows;
it does not step the SELECT. Rows.next calls Statement.step, which both executes
the VM and constructs owned SDK row values. The Io branch runs driver I/O and
returns Pending. Row.get_value then performs another Blob to_vec copy.

| Clock | Included work | Must not be claimed |
|-------+---------------+---------------------|
| prepare | Statement preparation and construction | Pure compiler CPU |
| query | Guard, reset, binding and Rows; direct form also includes prepare | SELECT execution |
| next | VM stepping, driver I/O work and first row construction | Separately measured VM-only or first-copy cost |
| owned_value | Row.get_value Blob copy and provider result construction | All materialization |
| Pending gap | End of Pending poll to next poll entry | Device-only latency |
| poll | Time inside Future.poll, including locks, synchronous I/O and preemption | Thread CPU |
| cleanup | Row/Rows destruction | Authoritative completion |
| outer residual | Runtime entry, clock/glue and uncovered teardown | An inferred additive I/O wait |

Poll and gap are nested inside stage wall time; never sum both with wall time.
The split form omits the private dangling-transaction check; the provider uses
explicit SQL BEGIN/COMMIT and never the driver's Transaction drop guard. This
assumption is source-reviewed and the split form remains diagnostic, not a new
production read path or semantic-equivalence theorem for arbitrary driver users.

* Observer design and validity

Only cfg(test) mounts tests/unit/native_read_timing.rs. Ordinary non-test builds
retain the exact original query branch; no new production feature or public API
is added. The unit suite reuses the existing concurrency_paired workload instead
of copying its authority/commit/recovery logic. A case callback arms observation
after preparation and disarms it after accepted jobs drain, before close/recovery.
Every per-read sample is bounded, includes result status/size but no body/key
content, and remains in temporary raw JSON outside Git. Collector append wait is
separate from the measured read, but remains in outer get/API timing.

A 100000-record per-case limit and preallocated per-thread buffers bound the
observer. Worker-local slots are assigned once per case generation; the collector
only drains them after accepted jobs complete. Contiguous sequence checks reject
missing/duplicate samples. Clock calls and serialization still have effects. Serialization is after
timed work and recovery. Compare intrusive direct reads with frozen uninstrumented
controls; never promote a dispatcher from intrusive clocks alone. Safety tests
cover immediate-ready versus Pending clocks, missing data, empty/65536-byte Blob,
65537-byte refusal and non-Blob corruption for both read forms.

** Retained global-recorder campaign and observer defect

The first serialized read-stage ABBA has 72 successful cases, 55296 exact
recoveries and 495936 read samples. All stage/count/nesting checks pass and no
read future returns Pending. It is useful public-driver boundary evidence, but
not tail-performance acceptance: the global observer mutex adds up to 17573.917
us to one append. The per-case mean append for independent/reuse reaches 8.139
us/read. This is observer interference, not intrinsic Turso time; it is outside
read.total but inside outer get/API timing. A/AV split-path median preparation
is 26.225/26.254 us and next is 9.356/9.050 us. No fixed native AV penalty follows.

The final observer removes per-read cross-worker locking. It preallocates one
buffer per blocking-worker slot before timing, uses a thread-local generation/
slot identity and unique atomic sample sequence, and merges only after drain.
The same OS thread exclusively appends to each slot. Slot/read limits fail rather
than silently dropping samples or reducing worker counts. No key, value, authority
decision, connection or borrowed guard is cached by the observer.

Three earlier pilot legs remain separately retained: one A leg followed by two
accidentally overlapping AV processes (54 successful cases). The overlap is an
orchestration error, not Host noise. These are excluded from paired attribution;
both processes drained and exited naturally. A new fixed serialized ABBA was
explicitly declared and completed before inspecting its results. No poor sample
is reclassified as passing or removed. The initial test-mount gate failure and
strict-Clippy unit-pattern failure are also retained alongside their fixes.

* Remaining measurable obligations

1. Measure per-thread CPU/preemption and process-scoped I/O for the original
   uninstrumented bad-tail path. Stage wall clocks do not separate preemption,
   driver locks, pure preparation CPU and FULL completion I/O.
2. Separately instrument SDK VM step versus initial Row construction if that
   split is required. Public Rows.next clocks deliberately keep these coupled;
   subsequent get_value copying is the only isolated materialization/copy here.
3. Review the existing driver prepare_cached API as a physical-statement-only
   experiment, before any runtime change: rebind every key, preserve reset and
   operation guards, read current transaction values and schema, discard unusable
   sessions and preserve cancellation/retirement/restart/Unknown rules. Never
   cache an authority decision, record value or send capability.
4. Keep direct paired uninstrumented end-to-end confirmation as the promotion
   gate. Favorable intrusive timing cannot repair the observed 0.200 TPS /
   11.105 P95 regression or certify either rejected dispatcher candidate.
